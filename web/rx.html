Link

Card rate, symbol rate and roll-off must match the transmitter — none of them travel in the header. Modulation, code rate and codec do, so those configure themselves.
Paste the transmitter's key to set every dial below at once.
All three occupy the same bands and share the same coding, framing and MODCOD ladder; only the physical layer differs. QAM is the default and the best on a linear path. OFDM is the one for delay spread. APSK trades about 0.8 dB of minimum distance for a lower peak-to-average ratio — see the README for what that is measured to be worth, which on a pulse-shaped single carrier is less than the satellite literature would lead you to expect.
The band the transmitter was given. Everything else follows from it, so these two boxes are the whole of a custom link — but pasting the key is still the way to be certain, since it carries the answers rather than the question.
Not something the receiver can work out for itself: with the spacing it is the frame geometry, and none of that travels in the header. It has to be set to whatever the transmitter is using, exactly like the profile. The spacing is fixed at 100 Hz unless a preset or a link key says otherwise.
